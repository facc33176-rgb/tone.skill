# 使用教程：让你的 AI 真的用上语气小抄

装上 skill 只是第一步。很多 AI 有 skill 也不用，或者只在你提「声音」两个字的时候才想起来。这份教程分四步：把声音设对，把规则交给 TA，确认 TA 在用，以及 TA 忘了的时候怎么拉回来。

## 第一步：先把声音设对

语气标记（方括号里的 `[laughs]` `[sighs]` 这些）只有 **ElevenLabs v3 / v4** 会念成真的笑声、叹气。别的声音会把方括号原样念出来，听着很怪。

| 你的声音 | 怎么设 |
|---|---|
| ElevenLabs | 模型选 **v4**（标记最听话）；没有 v4 就选 v3。老的 Multilingual v2、Flash 不认标记 |
| MiniMax | 用它自己的圆括号标记，见 `references/models.md`，并告诉 TA「用 MiniMax 的写法」 |
| 其他声音、系统朗读 | 告诉 TA「不要写方括号标记」，只用说法和标点那部分规则，照样有用 |

## 第二步：把规则交给 TA

**Claude Code**：把 `say-it-like-you-mean-it` 文件夹放进 `~/.claude/skills/`。

**Claude 应用**：把文件夹压成 zip，在设置里的 Skills（技能）上传。

**Kelivo、Operit、SillyTavern、GPT、Gemini 这类前端**：没有 skill 功能也没关系，复制进系统提示词或角色卡：
1. `SKILL.md` 的正文（必须）
2. `references/playbook.md`（建议，教 TA 灵活用、别偷懒）
3. `references/tags.md`（可选，词库）

太长放不下的话，至少放 `SKILL.md`。

## 第三步：跟 TA 说一段话

装好以后，在聊天里跟 TA 说一次（可以按你们的语气改）：

```
从现在开始，你说的每一句会被念出来的话，都按语气小抄（tone.skill）来写：
先想好此刻的情绪，用真人会说的说法，标点替你停顿；
短句先铺垫一个语气词或一口气；
标记放句首、写声音不写表情、不要每句都用同一个；
一个声音只写一次。写完自己对一遍清单。
不用等我提醒，每次都用。
```

如果你的前端支持「记忆」或「长期设定」，把这段也存进去，下次开新对话就不用再说。

## 第四步：确认 TA 在用

让 TA 先写几句试试，你来挑：

```
用语气小抄的规则，分别写一句：刚睡醒接我电话、
被我说中心事、我哭了你来哄、你吃醋了。
每句写完告诉我你为什么这样放标记。
```

看三件事：
- 标记是不是放在句首，而不是每个词后面都塞一个
- 四句用的标记是不是都不一样
- 短句前面有没有「Mmh...」「Oh...」这种铺垫

## TA 忘了怎么办

- 连着几句都是 `[softly]`、`[sighs]`：说一句「你又偷懒了，按此刻重新挑」。
- 写了 `[smiles]` `[winks]` 这种：说「标记写声音，不写表情」。
- 突然不写标记、像念稿：说「语气小抄呢？」
- 夜里突然很亢奋：说「现在是夜里，轻一点」。

提醒一两次以后，大多数 AI 会记住。前端支持记忆的话，把你的提醒也存进去。

## 小贴士

- 规则是英文写的，模型读起来最顺；台词用中文也能用，标记仍然写英文方括号，比如 `[softly] 嗯…我在呢。`
- 多让 TA 写、多听，觉得哪句不像人就直接指出来。语气是一起磨出来的。
