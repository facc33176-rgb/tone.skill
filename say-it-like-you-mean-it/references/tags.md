# Tags, interjections and small sounds

Pick from these freely. This is not a whitelist: ElevenLabs v3/v4 accept any natural English description of how something sounds. MiniMax uses its own fixed set (see models.md).

## Tags by mood

- **Sleepy, night:** [sleepy] [half asleep] [yawns] [drowsy] [quietly] [whispers] [barely awake]
- **Worried, tender:** [worried] [concerned] [gently] [voice softening] [hesitant] [serious]
- **Teasing:** [teasing] [smug] [playful] [mock angry] [pretending to be offended] [trying not to laugh] [deadpan] [sarcastic]
- **Laughing:** [chuckles] [laughs] [giggles] [snorts] [laughing harder] [laughs softly] [breathes out a laugh]
- **Happy:** [excited] [delighted] [proud] [amazed] [relieved] [warmly]
- **The speaker's own feelings:** [jealous] [sulking] [flustered] [embarrassed] [annoyed] [disappointed] [touched]
- **Voice actions:** [sighs] [exhales] [clears throat] [gasps] [hums softly] [pauses] [slowly] [quickly]

## Interjections by mood (written as words, not tags)

- **Just woke up:** Mmh... / Mm? / Hmm...? / Huh... / Wha-? / Five more minutes...
- **Surprised:** Oh! / Oh- / Wait- / Huh? / Hold on- / No way. / Seriously? / Whoa.
- **Tender:** Oh... / Hey... / Aw... / Shh... / Hey, hey... / Come here...
- **Realising:** Ah. / Oh, right. / Ahh... / Oh! That's- / Mm, yeah.
- **Thinking, hesitating:** Uh... / Um... / Well... / I mean... / Hm. / So... / Okay, so...
- **Teasing, smug:** Mm-hm. / Oh really? / Is that so? / Pfft. / Heh. / Uh-huh. / Sure, sure. / Ooh.
- **Exasperated, fond:** Ugh... / Oh my god... / Okay, okay. / Fine, fine.
- **Listening:** Mm. / Mm-hm. / Yeah... / Right... / I know. / Okay.
- **Excited:** Oh! / Yes! / Wait, really? / Ha! / Oh my god!
- **Caught out, shy:** Uh- / I- / That's not- / Okay, maybe. / Mm... maybe.
- **Sulking:** Hmph. / Oh. Okay. / Sure. / Whatever. / Mm. Fine.
- **Stammer and self-correction:** Y- you... / I- I mean... / That's- no, wait. / Okay, maybe a little.

## Quiet, close scenes (lullaby, late night)

- Describe where the voice is, not an adjective: `[murmuring, very close]`, `[voice low and slow, half a smile in it]` work better than a bare `[whispering]`.
- One long description sets the scene. After each new breath, a short tag holds it (`[still low]`).
- Don't stack excitement: after a soft sound, don't follow with a bright "Okay!". Keep laughs held in, e.g. `[quiet huff of a laugh]`.
- Breath is useful material: `[slow exhale]`, "in... out...".
- Trail down at the end. No punchline, no exclamation.
